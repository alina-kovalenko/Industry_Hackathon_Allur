# Проверка backend

Актуальный аудит исходников, исправления связки и пределы проверки описаны в [AUDIT.md](AUDIT.md). Разделы ниже сохранены как история прежних проверок.

## Интеграция готового frontend — 8 октября 2026

- Backend: **53 теста и 11 subtests прошли**. Дополнительно проверены изменение состояния, история, замена сценария, сброс, нулевая/полная остановка, проверки параметров, воспроизведение по времени и изоляция экземпляров сервера.
- Frontend: TypeScript и production-сборка Vite прошли; **11 тестов существующего симулятора прошли**. Из-за ограничения sandbox на чтение имени пользователя тесты запускались после компиляции TypeScript через `node --test`, вместо загрузчика tsx.
- Браузер Chromium: полный путь интерфейс → API → расчёт → изменённое состояние → история → сброс прошёл. Остановка окраски 60 минут даёт модельный выпуск 100,69 → 94,63. Воспроизведение переключает два тестовых среза, пауза останавливает переключение.
- Проверены desktop и мобильная ширина 390 px; горизонтального переполнения и ошибок страницы нет. Все внешние запросы заблокированы в тесте, интерфейс продолжает работать: внешние шрифты/CDN не требуются.
- Чистая установка Windows: новый Python venv, зависимости только из `wheelhouse` с `pip --no-index`; сервер и встроенный интерфейс ответили HTTP 200. `pip check` не обнаружил конфликтов.
- Временный HTTPS-туннель: проверены внешний GET интерфейса/health и POST сценария. Ссылка зависит от запущенных на ноутбуке сервера и туннеля; постоянный облачный хостинг не развёрнут.
- Dockerfile обновлён для сборки frontend и запуска API; Docker в среде отсутствует, контейнер не проверен.

Фактические KPI и модельные проекции разделены. На серверной вкладке три реальных участка из тестового набора; остальные вкладки исходного frontend содержат отдельную иллюстративную симуляцию. Состояние и история хранятся в памяти одного процесса. Дальнейшие исходные результаты относятся к предыдущей проверке проекта.

Проверено 7 октября 2026 года в локальном окружении Windows / Python 3.12:

- `python -m pytest -q`: **38 тестов прошли**, дополнительно 11 subtests. Проверяются KPI, нулевой выпуск, ограничение OEE, последовательный расчёт сценариев, статус оборудования, граница 60 минут, API, атомарный импорт, CORS и отсутствие будущих записей в запросах исторического прогноза.
- `python scripts/export_examples.py`: JSON-примеры и OpenAPI получены из текущего исполняемого кода. `/state` проверяется на точный состав полей.
- Повторное `python scripts/train.py` воспроизвело модель побайтно: SHA-256 `4fe1bd436b402f74abc07a673be09275b1ea053e90d36a7f5ba5dc9b258ec9b8`.
- Все 13 исходных файлов загружены с проверкой контрольных сумм; сводные профили трёх источников рассчитаны отдельно.
- `pip check`: конфликтов установленных зависимостей нет.

Есть предупреждение совместимости: Starlette сообщает о будущем переходе TestClient с httpx на httpx2. На закреплённых версиях тесты проходят.

Docker-конфигурация включена, но Docker не установлен в среде проверки; сборка контейнера локально не проверена. Результат GitHub Actions следует смотреть отдельно в репозитории. Промышленная точность модели, причинный эффект сценариев и подключение к оборудованию не проверялись.
